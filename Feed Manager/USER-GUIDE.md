# 操作手册

> 这是**操作手册**：配置细节、日常指令全表、出状况怎么办。
> 还不知道这是什么、能干嘛 → 先看 [README.md](README.md)。想看 AI 执行的工作流规范 → [SKILL.md](skills/stock-kol-watch/SKILL.md)。

装好之后（在 Followin-Skills 仓库根目录下 `cp -rn "Feed Manager/skills/"* ~/.claude/skills/`），只想试一次就说"用这 5 个账号跑个快速简报"，不用配任何东西。**下面全部是想长期累积（🅰️ 模式）才需要的。**

---

## 1. 配置

### 1.1 笔记库路径

```bash
export KOL_VAULT="/你的笔记库路径/Stock-Watch"
```

写进 `~/.zshrc` / `~/.bashrc` 持久化。所有产出都落在它下面。设了这个变量，以后说"跑一下 KOL"默认走落盘模式。

### 1.2 关注名单落位

内置的 5 个 starter 在 [account-roster.md](skills/stock-kol-watch/references/account-roster.md) 顶部。**把它们复制到 `$KOL_VAULT/references-roster.md`**——skill 目录里那份是模板，实际运行读的是 vault 里这份，改名单改这里。

⚠️ 这 5 个偏半导体、**没有唱空账号**。正式用前补 1-2 个稳定质疑的声音，否则你的名单会系统性地只给你看多的理由。

### 1.3 收尾门禁 hook（可选，强烈推荐）

在 `~/.claude/settings.json` 加：

```json
{ "hooks": { "Stop": [ { "hooks": [ { "type": "command",
  "command": "KOL_VAULT=/你的笔记库路径/Stock-Watch bash ~/.claude/skills/stock-kol-watch/scripts/daily-gate-check.sh",
  "timeout": 15 } ] } ] } }
```

⚠️ **vault 路径必须内联在命令里**，别指望它读你 zshrc 里的 export——hook 进程不一定继承，继承不到时门禁**静默失效**，你不会收到任何提示。

**它在管什么**：你跑完日报想结束会话时，机械检查这几件事，没做全就拦住不让结束——把"我以为写了"变成"系统不让我糊弄"。

| 检查 | 说明 |
|------|------|
| `Daily-Index.md` / `Macro.md` / `_Sectors-Index.md` 今天动过 | 每批必然会变的三个文件 |
| `Portfolio.md` 今天动过 | **仅当你确有持仓时**才要求；还没报持仓不会被拦 |
| 日报里有账号覆盖表 + 完整性审查 | 证明拉取和校验环节没跳过 |
| 日报底部 `sector-sync` 声明的板块文件确实动过 | 防"只改索引日期不改板块笔记" |

**装完自检一次**：故意把 `Macro.md` 的修改时间改成昨天（`touch -t 202601010900 $KOL_VAULT/Macro.md`），再结束一个跑过日报的会话——**被拦住 = 装对了**。没被拦说明 hook 没生效，回去检查路径。

## 2. 第一次跑（冷启动）

新笔记库是空的。第一次直接说：

> **「初始化一下 vault，然后跑一下 KOL」**

它会：

1. 建目录（`Daily/` `Tickers/` `Sectors/` `Weekly/`）+ **8 个种子文件**
   `references-roster` · `Portfolio` · `Decisions-Journal` · `Pre-Trade-Checklist` · `Macro` · `Daily/Daily-Index` · `Sectors/_Sectors-Index` · `_last-pull`
2. 问你**持仓、现金（含货基）、时区**
3. 拉一遍名单，产出第一份日报

之后每天就一句"跑一下 KOL"。

> 💡 没有持仓也能跑——它会照常出日报和板块笔记，只是持仓相关的段落留空。想先观察一段时间再建仓，这样用完全合理。

## 3. 日常指令全表

### 拉数据

| 你说 | 它做 |
|------|------|
| 「跑一下 KOL」/「拉最新数据」 | 全量拉名单 → 日报 → 更新标的/板块笔记 → 校准价格 → 过门禁 → 汇报最该看的 3 点 |
| 「补一下昨晚的」/「晚拉」 | 从上次断点增量拉，**合并进当天同一份日报**（不会变成两份打架的文件） |
| 「拉 12h」/「拉最近一周」 | 按你给的窗口拉，不用默认的自然日切分 |
| 「今天只看 @XX 和 @YY」 | 本次只拉这两个（会在覆盖表里标明其余未拉，不会假装拉全了） |

### 交易与决策

| 你说 | 它做 |
|------|------|
| 「我买了 XXXX 100 股 @ $85」 | 更新持仓表 + 标的笔记 + 板块笔记 + **新建一条决策记录**（含 1周/1月/3月回顾提醒） |
| 「我卖了…」/「我清仓了 XXXX」 | 同上，并在决策日志里记录了结 |
| 「XXXX 现在能买吗 / 要不要加仓」 | 跑 5 项买卖前检查，列完状态**让你自己决定** |
| 「给我个 XXXX 的止损策略」 | 给 4-5 个**带依据**的触发条件候选让你挑 |
| 「决策 #3 的回顾我来填：判断错了，因为…」 | 更新回顾字段 + 归纳进决策模式索引 + 把教训写进买卖前检查表 |

### 查历史

| 你说 | 它做 |
|------|------|
| 「给我看 XXXX 的所有观点」 | 读 `Tickers/XXXX.md`（价格历史 + 谁在什么时候说过什么 + 反方 + 你的仓位） |
| 「XXXX 板块怎么演变的」 | 读 `Sectors/<板块>.md` 的强度评级表 |
| 「@XX 这个账号最近在说什么」 | 读日报里对应的账号段落 |
| 「过去一周发生了什么」 | 读 `Daily/Daily-Index.md`（每天一行 TLDR） |

### 维护

| 你说 | 它做 |
|------|------|
| 「加一个 @XX」/「去掉 @YY」 | 本次运行调整，并问你要不要写进名单文件（**不会擅自改**） |
| 「跑周报」（或周末跑日报时它会问） | 5 节复盘：持仓/板块演变、KOL 行为、账号质量 review、**你的决策对错复盘**、下周日历 |
| 「@XX 最近质量下降了」 | 记录观察；**评级变动是周维度的事**，且要你确认后才改 |

## 4. 输出在哪看

| 想看 | 打开 |
|------|------|
| 今天发生了什么 | `Daily/YYYY-MM-DD.md` |
| 30 秒回查过去几天 | `Daily/Daily-Index.md` |
| 我的持仓全景 + 挂单 | `Portfolio.md` |
| 某只票的全部历史 | `Tickers/<代码>.md` |
| 某板块怎么演变 | `Sectors/<板块>.md` |
| 我的每个决策 + 回顾 | `Decisions-Journal.md` |
| 买卖前该检查什么 | `Pre-Trade-Checklist.md` |
| 本周复盘 | `Weekly/YYYY-W##.md` |

日报本身分两区：**上半部分是"现在的状态"**（每次拉取覆盖成最新值），**下半部分是"发生了什么"**（按批次追加，不删旧）。所以一天拉三次，日报顶部永远是最新判断，中部是完整的信号流水。

## 5. 出状况怎么办

**我忘了报成交，过了好几天才想起来**
直接说"我 X 月 X 日买了 XXXX N 股 @ $Y，之前忘了说"。它会补记并按当时日期建决策记录。**越早说越好**——持仓错着，浮盈、仓位占比、论点健康度会一路错下去，而且**没有任何告警**（它不接券商，无从校验）。

**好几天没跑，断档了**
照常说"跑一下 KOL"。它读上次的断点，发现超过 36 小时会在日报顶部标注断档时长并自动放宽窗口。⚠️ 如果某个账号这几天发得多，一次可能拉不全——脚本会告警"本页最早一条仍晚于起点"，看到就让它翻页补拉。

**结束会话时被门禁拦住了**
说明有该更新的文件没更新。它会逐条列出缺什么，让它补完再结束。**不要用 touch 文件的方式糊弄过去**——门禁存在的唯一意义就是防这个。

**某个账号拉取失败**
覆盖表里会标 ❌。少数几个失败让它单独重试即可，不用重跑整批。

**它拒绝给我一个具体价位**
这是设计。没有数据或明确原则支撑的数字它不给，只给定性方向。想要具体数，就给它一个可计算的锚（"按 50 日均线算"/"按仓位回到 30% 算"）。

**我想换掉整个名单**
改 `$KOL_VAULT/references-roster.md`，下次跑自动生效。建/评/养名单的方法论见 [account-roster.md](skills/stock-kol-watch/references/account-roster.md)。

**想加实盘仓位 / 卖方研报这些进阶层**
见 [advanced-extensions.md](skills/stock-kol-watch/references/advanced-extensions.md)（7 节，每层都写了怎么加和已知陷阱）。核心版刻意不带这些，跑顺手了再加。

## 6. 上手清单

1. `export KOL_VAULT=...`
2. 把 5 个 starter 复制进 `$KOL_VAULT/references-roster.md`（并补一个唱空的）
3. 配 hook（可选）+ 自检一次
4. 说「初始化 vault 并跑一下 KOL」，告诉它你的持仓和现金（含货基）
5. 以后每天一句「跑一下 KOL」；**成交了就报一句**
