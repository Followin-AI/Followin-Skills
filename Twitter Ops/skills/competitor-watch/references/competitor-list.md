> ⚠️ **初始化文件** — 全是占位符，**填你自己的账号**。SKILL.md 的周扫、performance-review 的 Step 0 行业基线、选题环节的撞车查重都读这张表。

名单只有两类角色（含义见 SKILL.md 开头）：**🎯 BENCHMARK = 老师**（学 voice / hook / Pattern），**📏 BASELINE = 坐标**（只取基线数字，不学 voice，不互动）。

---

## 🎯 BENCHMARK 对标（建议 5–6 个）

准入：粉丝量在你的 **1.3x–10x**（甜蜜区，太大是"仰望型"陷阱）＋ 定位有交集 ＋ **最近 30 天你真的从他身上抄到过东西**。

| 账号 | 粉丝 | 中位 views | 定位 | 学什么（具体到可执行） | 可互动 |
|---|---:|---:|---|---|:--:|
| @[账号1] | [数字] | [数字] | [定位] | [如：开头必用反问 / 每条配 5–10 张图] | ✅ |
| @[账号2] | | | | | ✅ |
| @[账号3] | | | | | ✅ |
| @[账号4] | | | | | ❌ 受众不重叠，只学不互动 |

> 「学什么」一栏必须写成**能直接照做的动作**，写"内容质量高"等于没写。

## 📏 BASELINE 行业基线（建议 4–5 个）

准入：同赛道、已确立市场位置的账号，用来量"行业地板和天花板在哪"。**通常是机构/媒体号 → 一律不互动。**

| 账号 | 粉丝 | 中位 views | 日均发推 | 这个号说明什么 |
|---|---:|---:|---:|---|
| @[账号A] | [数字] | [数字] | [数字] | [如：低频高质路线的天花板] |
| @[账号B] | | | | [如：高频铺量的天花板 —— 粉丝 4x 但触达只有 2.7x，看到即警告] |

> 基线里同时放**正面范本**和**反面锚点**很有用：反面锚点回答的是"如果我继续走这条路，几年后顶配长什么样"。

## 扫描节奏

| 对象 | 频率 | 做什么 |
|---|---|---|
| BENCHMARK | 每周（可对最关键的 2–3 个提到每日） | Top 3 推文的开头句式、有没有可直接复用的格式 |
| BASELINE | 每周 | 只取 中位 / max / 发文量 及其 WoW Δ% |
| 全量沉淀 | 每周固定一次 | ≥2 次出现的句式 → 写进 performance-review 的 `patterns.md`；全员空白话题 → 进下周选题池 |
| 名单审计 | 每月 | 升降级、补新目标、清理停更账号 |

## 维护规则

- **存活性**：`twitter(action="user_info")` 查不到，或最新推距今 >30 天 → 标「疑似停更/改名」，人工核实后再删或改 handle。**别标 N/A 了事**——死号数据会被误读成自己的采集故障。
- **手动核对 handle 拼写**：拼错一个字母就会连续几周"采不到数据"却查不出原因。
- **降级/移出的理由要写进下面的变更记录**，否则三个月后没人记得为什么删的。
