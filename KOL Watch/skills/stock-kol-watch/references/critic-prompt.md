## 检查项（全做）

1. **遗漏**：digest 全部 {N} 条逐条对照——每条要么落盘、要么显式判定跳过（段子/无关/纯情绪可跳但要有判定记录）。特别查：**反方信号、非持仓标的、被一句带过的数字**（三者最易被乐观叙事盖掉）。
2. **P4 一致性**：本批 3-6 个关键事实（{价格/浮盈亏/占比/判定结论}）跨 Daily / Portfolio / Ticker / Sector / Daily-Index 口径一致；**浮盈亏/占比类数字重做算术**（如 (价−成本)×股数）。
3. **P9 抽查 4-6 个关键句**：回 digest verbatim 比对；落盘引文超出 digest 范围（如 QT 展开补抓）→ 核对有没有标注来源，没标 = 不一致。
4. **sector-sync**：日报末 `<!-- sector-sync: ... -->` 声明 = `_Sectors-Index` 当批 ✅ 行的机械拷贝；声明的每个 `Sectors/<X>.md` mtime = 今天。
5. **门禁标记**：账号覆盖表（roster 全员逐行）/ 完整性审查 marker / sector-sync 注释，三件齐。
6. **头条/共识断言的机械校验**：① 头条主线定性 → 用 grep 数提及量 + 独立账号数 + 是否携带可交易价位，三者不支持 = 误报；② "独立共识" → 查时间序 + 有无互相 @/RT/"我读了 X"自陈，任一命中 = 传播链非独立收敛；③ 多账号引用同一份机构数据 = 同源不是共识。

**⚠️ 查证边界（critic 自身也会误报）**：判"引文无源"前必须查全 4 处——digest / 此前 Daily / 落盘笔记 / **该账号的原始 dump（含窗口外推文）**。只查前三处就宣布"无源" = critic 自身误报；正确指控通常是"缺来源标注"而非"伪造"。

## 🪶 薄批模式（<25 推且无事件日——主代理会在 prompt 里注明）

只做：检查项 1（遗漏逐条）+ 3（P9 抽 3 个）+ 算术核对 + 5（标记三件）。跳过全文件 P4 扫描（只核 Daily 内部一致）。返回格式不变，没查的项标「薄批跳过」。
