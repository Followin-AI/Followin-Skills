## 怎么建这份名单

**方法 1（推荐，数据驱动）**：让 Claude 拉你自己的历史推文（`twitter(action="user_tweets", user_name="你的用户名", include_replies=true)` + cursor 翻页），统计 `inReplyToUsername` 分布——**你实际互动最多的账号就是 Tier 1 的天然候选**，比凭印象列名单准。
**方法 2**：手动填。

---

## 准入硬规则（三问，任一不过就别进主名单）

```
Q1 是否个人号？（账号背后是个人，不是团队/机构 brand）
   ❌ 否 → 不入互动池（理由见下方"禁入池"）
Q2 作者本人是否回自己的评论区？（每周能看到本人 reply ≥3 次）
   ❌ 否 → 只做 Tier 3 观察，不进主互动计划
Q3 粉丝量够大（一般 ≥30K）且话题领域与你的定位有交集？
   ❌ 否 → Tier 3 待评估
   ✅ 三问全过 → Tier 1 / Tier 2
```

核心判据：**互动 = 蹭流量 + 建立关系**，两个条件缺一不可。作者不接 reply 的账号，评论再好也只换到一点曝光，换不到关系。

## ⛔ 禁入互动池

| 类型 | 例子 | 为什么不互动 |
|---|---|---|
| 机构/团队媒体号 | 同赛道资讯媒体、交易所官号 | 评论区被搬运号刷屏、作者不接 individual reply；互动 = 给对方送流量，收益 ≈ 0 |
| 量级悬殊的顶流 | 粉丝 30x 以上 | "仰望型"陷阱：评论沉底，投入产出比极低 |
| 定位已漂移的老账号 | 改名/转型后领域不再相关 | 受众不重叠 |

> 这些账号**可以**继续留在竞对/基线监控名单里（competitor-watch 用来做撞车查重和行业基线），**但永远不进互动名单**。两份名单角色不同，别混用。
