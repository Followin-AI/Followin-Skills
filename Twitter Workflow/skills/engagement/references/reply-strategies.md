# 评论与回复模板库

SKILL.md 的配套模板库。Outbound 写评论、Inbound 回评论时**直接打开这份文件取句式**，别现编。
所有模板都是填空式的——`[方括号]` 里必须换成你手上的真实数据/观点，填不出来就说明这条评论没料，不要发。

---

## 一、Outbound 主动评论模板

### 1. 📊 深度见解型（核心，占比最高）

逻辑链：观察 → 推理 → 结论。2–4 句。

```
A. "补充一个数据：[具体数字]。从这个角度看，[推理]。关键变量是 [X]。"
B. "同意大方向，但 [具体环节] 可能被低估了。[数据]。"
C. "这里有个细节：[细节]。历史上类似情况出现过 [X 次]，结果是 [Y]。"
D. "[反向思考]。不是说观点错了，而是还有一个风险没定价：[风险]。"
```

### 2. 🔥 犀利观点型

一句话立场清晰，可尖锐但不人身攻击，要有逻辑不能纯情绪。

```
A. "说白了就是 [一句话犀利总结]。"
B. "[现象] 说明什么？说明 [犀利判断]。散户永远最后知道。"
```

### 3. 💬 互动引导型

以提问或半开放判断收尾，让原作者或围观者有回复欲。

```
A. "这让我想到一个问题：[问题]？有人研究过吗？"
B. "如果 [假设条件]，这个逻辑还成立吗？"
```

### 4. 😤 幽默/吐槽型

1–2 句，增加"活人感"。可自嘲、可嘲讽现象，不嘲讽个人；真的好笑才发。

```
A. "[荒谬现象的幽默总结]。这行永远不让人失望。"
B. "看完这条我的反应：[简短反应]。然后看了眼持仓，又冷静了。"
```

### 5. 在 KOL 帖子下补数据

```
"补充一个数据点：[数据]。
从这个角度看，[你的独特观点]。
[可选：@ 另一个相关账号，形成三方讨论]"
```

### 6. 在热门话题下抢位

```
"大家都在讨论 [话题]，但忽略了一个关键变量：[变量]。
[1-2 句数据支撑]。
这才是决定走势的核心。"
```

## 二、Inbound 回复模板

### S 级质疑：四选一（选哪个见 SKILL.md §2.2）

**A. 承认 + 补充**（质疑合理）
```
"你指出的 [点] 确实是我没考虑到的。
补充看了一下 [数据/来源]，[新发现]。
原来的结论需要修正：[修正后的观点]。
感谢，这个角度很有价值。"
```

**B. 承认部分 + 坚持核心**（部分合理）
```
"[具体点] 你说得对，这里我表述不够严谨。
但核心逻辑不变：[你的核心论点]。
因为 [数据/逻辑支撑]。
两个角度其实不矛盾，关键看 [条件]。"
```

**C. 用数据反驳**（质疑不合理）
```
"理解你的观点，但数据不支持这个判断。
[指标 A] 是 [数字]，[指标 B] 是 [数字]。
如果 [他的逻辑] 成立，那 [反推结果] 应该出现，但实际没有。
当然市场不确定性大，继续观察。"
```

**D. 冷处理**（对方在抬杠）
```
"数据摆在那了，各人判断。"
[或者不回复，只点赞表示看到了]
```

### B 级借势：四种手法

```
引申型："你提到 [X]，让我想到一个更大的问题：[延伸观点]"
数据补充型："说到这个，刚好看到一组数据：[数据]"
预告型："这个话题展开讲太长了，下一条推文专门说说"
互动型："好问题，我想先问问大家怎么看：[提问]"
```

### 场景化模板

**1. 被质疑数据准确性**
```
"感谢指正。数据来源是 [来源]，我再核实一下。
如果有更新会第一时间修正。
不过核心观点 [观点] 不受这个数据点影响——因为 [逻辑]。"
```

**2. 被说是马后炮**
```
"理解。回看确实像马后炮，但当时的判断逻辑是：[逻辑链]。
更重要的是现在怎么看：[当前观点]。
市场永远是对的，我只是提供一个分析框架。"
```

**3. 有人问操作建议**
```
"不做投资建议。但从数据角度看：
- [事实 1]
- [事实 2]
风险自担，DYOR。"
```

**4. 对方发了你不同意的观点**
```
"有意思的角度。不过还有一个维度值得考虑：[你的数据/逻辑]。
从 [具体指标] 来看，情况可能更复杂。
两种可能都存在，关键看 [什么条件触发]。"
```

**5. 新粉丝提基础问题**
```
"好问题，简单说：[简洁回答]。
如果想深入了解，建议看 [资源]。
之前也写过一个线程，搜 [关键词] 可以找到。"
```

**6. 被无理攻击**
```
[不回复，或者简短一句]
"数据摆在那儿，各人判断。"
[如果持续骚扰，直接 mute/block]
```

## 三、互动节奏指南

| 时段 | 动作 | 时长 |
|------|------|------|
| 早间 | 检查过夜互动，回复质疑 | 15 分钟 |
| 午间 | 主动在 3-5 个目标账号帖子下评论 | 10 分钟 |
| 晚间 | 回复当日评论，参与热门讨论 | 15 分钟 |

时段按你受众的活跃时区调整——上表是"三段式"的骨架，不是具体钟点。
