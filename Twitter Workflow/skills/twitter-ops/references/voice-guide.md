# 人设 & 语气指南

> **这是整套流水线里最重要的一份文件**——所有推文产出都基于它。
> 但**不要凭自我认知直接填**：你的语气不在你以为的样子里，在你已经发过的东西里。

---

## 先选一条路

```
你有 30 条以上的历史推文吗？
├── 有   → 路线 A：让 Claude 从你的推文里提取（最准）
└── 没有 → 你能说出 3 个你欣赏的账号吗？
          ├── 能   → 路线 B：引导问答，半小时填完
          └── 不能 → 路线 C：先定最小可用版，跑两周用数据回填
```

### 路线 A — 从历史推文提取（推荐）

对 Claude 说：

> **「读一下我最近 50 条推文，帮我填 voice-guide」**

它会拉你的历史推文，然后从**实际用词**里归纳：高频开场方式、标点习惯、emoji 使用密度、
句子长度分布、你反复用的比喻类型、以及你从来不写的东西。

这条路最准，因为**它看的是你实际发出去的，不是你以为自己是什么样**。
很多人自认「专业克制」，实际推文里每三条就有一次吐槽——那才是你的语气。

填完自己过一遍，把不认同的地方改掉。**分歧处值得多想一下**——通常是「我希望自己是」和「我实际是」的差距。

### 路线 B — 引导问答

新账号没有历史数据，就从这几个问题入手。**别答形容词，答具体的**：

| 问题 | 为什么问这个 |
|---|---|
| 你最近转发或收藏过哪三条推文？具体是哪句话打动你？ | 你欣赏的表达方式 ≈ 你想成为的表达方式 |
| 朋友怎么形容你说话？（挑刺的那种形容） | 别人眼中的你比自我描述准 |
| **你绝对不会说的话是什么？** | 红线比正面描述好答十倍，而且更管用 |
| 你写完一段话，最常删掉的是哪部分？ | 揭示你的自我审查方向 |
| 你更愿意被人说「看不懂但很牛」还是「讲得真明白」？ | 决定信息密度和解释深度 |
| 遇到自己看错的时候，你会公开认吗？ | 决定能不能立「敢认账」的人设 |

把答案交给 Claude，说「按这些填 voice-guide」。

### 路线 C — 最小可用版

前两条都答不上来，就只填**三个必答项**，其余留空：

1. **不做什么**（红线，见下方 ❌ 那节）
2. **信息密度**：读者看完是「记住一个数字」还是「记住一个观点」
3. **人格化程度**：读者认的是「这个人」还是「这个信息源」

然后正常跑两周。跑完说「帮我分析账号数据」，`performance-review` 会用真实互动数据把剩下的填上——
**那时候填的比现在猜的准。**

## 模板

### 核心人设

**身份**：`[一句话。不是职业，是你在读者那里的角色——比如「帮你把宏观翻译成人话的人」]`

**风格 DNA**：

| 维度 | 你的选择 | 怎么判断 |
|---|---|---|
| 信息密度 | `[高/中/低]` | 一条推文塞几个数据点？高 = 3+，低 = 一个观点讲透 |
| 观点强度 | `[强观点/客观+点评/纯信息]` | 你敢不敢在还没定论的时候先站队 |
| 人格化程度 | `[强人设/编辑部/机构]` | 读者取关时，是取关「你」还是取关「一个源」 |
| 语言风格 | `[口语/正式/混合]` | 你会不会用「卧槽」「离谱」这类词 |
| 互动倾向 | `[主动/输出/混合]` | 你发完推文会不会去回复评论 |

### 标志性语言元素

> ⚠️ **这一节最好由路线 A 生成。** 口头禅是无意识的，自己想不出来。

- **高频开场**：`[从历史推文里统计出来的，不是你以为的]`
- **标点习惯**：`[破折号？省略号？中英文之间空不空格？]`
- **emoji**：`[频率 + 常用的那几个 + 各自什么时候用]`
- **你的比喻取材**：`[体育？做饭？打游戏？这个特征比用词更难模仿]`

### 内容调性

**✅ 可以做**
- `[例：用数据说话，但每个数据都给来源]`
- `[例：自嘲，但不自贬]`

**❌ 不能做**（**这一节最重要，先填这个**）
- `[例：不做价格预测]`
- `[例：不给投资建议]`
- `[例：不蹭与自己无关的热点]`
- `[例：看错了不装没看见]`

> 💡 红线比正面描述更管用：**正面描述会被写成套话，红线会真的拦住东西。**

## 什么时候回来改它

- **跑完第一次 `performance-review`**——用真实数据回填「高表现模式」和配比
- **你发现自己反复否掉 Claude 的稿子**——说明 voice-guide 和你真实偏好有偏差，把否掉的理由写进 ❌ 那节
- **账号定位变了**——比如从纯搬运转向出观点，身份和观点强度都要跟着改

> ⚠️ **别一次性写完美。** 这份文件是跟着账号长的，第一版只要能让稿子「不难看」就够了。
