# 📦 推文素材库 Vault

> ⚠️ **初始化模板** — 每次复盘的"内容入库"环节往这里追加（performance-review §6）。
> 首次建库：让 Claude 扫历史推文，或用 `scripts/tweet_analyzer.py` 离线跑一遍。

## 入库标准

```
ER = (点赞 + 转发 + 评论) / 浏览数        ← 与 SKILL.md 同一口径，用比率不用绝对数
🏆 S 级：ER Top 10%        → 必入库，深度拆解
⭐ A 级：ER Top 25%        → 入库，提炼模式
📌 观察：ER > 均值 1.5 倍  → 标记
🚫 反面：ER 垫底           → 也要记，标"避坑"，避免重蹈
```

⚠️ `scripts/tweet_analyzer.py` 的内置公式把**引用数也算进分子**、分母用 impressions，和上面差一点。同一批数据只用同一个口径排序，别把脚本结果和手算结果混着比。

粉丝量在涨，早期推文绝对数低但比率可能更高——所以永远按 ER 排，不按点赞数排。

## 维护

- 每次复盘追加当期 S/A 级。
  🔴 **追加前先按 `tweet_id` 查重，已在库的跳过、只更新数据，不许再插一条。**
  周报窗口和月报窗口是重叠的（月报覆盖 4 个周报窗口），**同一条推文必然被扫到两次**——
  没有去重键就会重复入库，而下游 `patterns.md` 的准入闸是「**至少出现 2 次**」，
  于是**一条只发生过一次的偶发爆款被记成 2 次，升格为"✅ 稳定模式"**，
  再反哺选题打分和 Pattern 匹配。一次运气就这样被制度化成"实证模式"，且计数错误完全不可见。
- 每月重算"高频成功模式"排名（写进 `patterns.md` **§三那一张表**，见该文件的重算边界说明）
- 超过 6 个月没被引用的条目标"冷库"，不删除
  —— 判据是本模板的 `最近引用` 字段；**该字段为空的条目按"从未引用"处理，以 `入库` 日期起算**。
