topic-engine §4 的详解版。每话题选 3 个**不重复**的 Pattern 生成 3 个角度。
下面的 Hook 示例用 `$资产` / `X` / `{占位}` 表示可替换对象，**不锚定任何具体年份或事件**——照抄年份会让内容一眼过时。

---

## 1. 🔥 直击对立观点（4-24h）
**模式**：大多数人说 X，但实际上 Y 才是真的。
**Hook 示例**
- "所有人都在说 $资产 会破新高，但没人注意到链上大户在持续出逃"
- "市场以为央行会转向宽松，结果通胀数据一出……"
- "$资产 质押量高歌猛进，但这波流动性缺口谁来背？"

**适用**：热点共识 / 政策反转 / 链上动作与市场预期相反。
**数据支撑**：持仓变化、期货未平仓、机构流向。

## 2. 📊 数据讲故事（4-48h）
**模式**：用 3-5 个具体数字建立因果链条。
**Hook 示例**
- "$资产 供应分布：交易所余额创 N 年新低，而大户囤积破历史高位。说明什么？"
- "上周股指跌 8%，而 $资产 涨 3.2%。这不是巧合"
- "稳定币发行量 8 周跌 15%，但市场还在喊底部……数据不会骗人"

**适用**：链上指标 / 市场结构 / 宏观数据传导 / 项目基本面。
**必须包含**：≥2 个可验证的具体数字。

## 3. 🔄 反向风险警告（4-48h）
**模式**：所有人看好，但暗藏的风险是……
**Hook 示例**
- "这波反弹看似强劲，但大户头寸杠杆率已到 N 年高位。一根大阴线就连环爆"
- "现货 ETF 吸金 N 亿听着很牛，但这笔钱多数来自别的资产出逃——那边一反弹，钱就走"
- "某主流币重大协议升级顺利完成，但验证者集中度反而上升了，中心化风险被忽视"

**适用**：利好背后的风险 / 结构性脆弱（杠杆、流动性、集中度）/ 技术面与基本面背离。
**必须包含**：一个具体的「爆炸点」或触发条件。

## 4. 📈 历史平行线（24h+）
**模式**：这次和上一轮 X 情况一样，结果是……
**Hook 示例**
- "上一轮某头部人物公开与 $资产 切割时，价格跌了一半。这次的对标事件是 X，会重演吗？"
- "上一轮融资热潮顶点，绝大多数项目最后归零。这一轮的新赛道热度一模一样"
- "上轮熊市末端链上活跃地址跌到 N，这次还有 M——中间的差距就是下跌空间"

**适用**：市场周期 / 政策史 / 项目风险重演。
**必须包含**：≥2 个可对比的时间点和数据。**禁止**写死具体年份当卖点，改用"上一轮 / 上一次同类事件"。

## 5. 😤 嘲讽吐槽（4-24h）
**模式**：某个荒谬之处明显到只能笑。
**Hook 示例**
- "监管方一边说这行业全是骗子，一边批了同类产品，一个月吸了 N 亿"
- "某 L2 自称『终极扩容方案』，实测吞吐量还不如上一代。这是喜剧吗"
- "听『分析师』教你交易，就像听一个连出三次事故的人教你开车"

**风格**：不是单纯骂，要指出荒谬性；可温和讽刺但不人身攻击；有数据更有力。

## 6. 🚀 破局新视角（24h+）
**模式**：换一个框架解读热点，揭露本质。
**Hook 示例**
- "你们争 A 和 B 谁更值钱，但本质是封闭资本 vs 开放平台的战争，输的永远是散户"
- "收益率越来越低不是坏事，是这条赛道从赌场变成基础设施的信号"
- "这个新赛道的真问题不是技术，是宏观：母板块一进熊市，流动性直接蒸发"

**必须包含**：一个新的视角或概念框架。

## 7. ⚡ 突发快评（<4h）
**模式**：事件刚发生，立即给出最独特的解读。
**Hook 示例**
- "央行突然转口风，市场欢呼——但这恰恰是风险开始的信号"
- "媒体爆料某国考虑把 $资产 纳入储备，散户在追，可机构三个月前就建好仓了"
- "某交易所遭攻击，市场砸盘 2%。真正该问的是：这笔钱最后流去哪"

**风格**：速度最快、观点最独特；别等信息齐全，趋势判断比事实复述更值钱；指出真机遇或真风险。

## 8. 🎓 深度教育 Thread（24h+）
**模式**：一个话题拆成 5-10 条逻辑清晰的线程。
**Hook 示例**
- "很多人问为什么供应减少反而不涨？讲讲『供应稀缺悖论』：真正定价的是流动性"
- "质押经济学为什么可能是陷阱？拆一个常见的认知错误"
- "理解清算机制要懂 3 个概念，多数人只知道 1 个，所以每次暴跌都被清"

**风格**：开头吸引 + 内容有深度；每条能独立存在；最后一条给实操建议。

## 9. 🎯 对比分析（24h+）
**模式**：两个相似的东西，区别在哪、哪个更值钱？
**Hook 示例**
- "A 链 vs B 链：表面都是高吞吐，但一个是完整生态、一个是母链旁支，这决定了流动性分布"
- "同一资产的 ETF vs 信托：费率差 2%，但风险结构完全不同"
- "两个同代 L2 用的是不同证明机制，安全假设差在……"

**必须包含**：≥2 个量化差异 + 1 个逻辑推论。

## 10. 💡 交易洞察（4-24h）
**模式**：基于一个观察给出操作方向（**不预测价格**）。
**Hook 示例**
- "交易所净流出创 N 月新高，而市场情绪贪婪——这是反向信号"
- "$A/$B 比值跌到历史低位区间，机构在重新评估配置比例"
- "稳定币进场量突增但链上活动没跟上，这轮反弹信号混乱，风险 > 机会"

**风格**：给观察、给建议，不预测涨跌；强调风险认知；可直接指导操作。

## 11. 🌍 宏观视角 / 跨界传导（24h+）
**模式**：把微观事件套进更大的经济周期框架。
**Hook 示例**
- "全球流动性在收紧（长端收益率 N%），但 $资产 还在涨——钱在从哪里流向哪里？"
- "通胀降下来了，实际利率却仍为负。这是持有风险资产最被低估的理由"
- "某国货币持续贬值，而 $资产 是全球流动资产——下一波接盘资金可能来自那里"

**必须包含**：宏观数据 + 与标的的明确联系。

## 12. 🌊 叙事追踪（24-72h）
**触发**：trend-scout 叙事热度榜 ≥3.0/5 的板块（带 `🌊 narrative` tag）。
**定位**：板块爆发时不做"跟风播报"，做"差异化深度解读"——让读者觉得"看这一版省时间"。

| 模式 | 适用 | Hook 模板 |
|---|---|---|
| 🔍 深度成因拆解 | 成因复杂 | "X 为什么这周突然爆发？3 个时间节点交汇 → …" |
| 🌉 跨界传导映射 | 可跨市场映射 | "X 是那边的事，但这边有 3 个等价标的：$A / $B / $C" |
| 🎯 对照差异化 | 挑被低估的二线 | "X 涨疯了，但 Y 才 +6%，catchup 概率…" |
| 🔄 反向风险 | 板块过热 | "X 4 周累计 +95%，历史同涨幅后 2 周内回撤 30% 的概率是 N%" |

**5 要素硬要求**：核心观点含 ≥2 差异化数据点 / 反共识选「结构·反向·延伸」三选一（不选时间）/ Hook 必含一个数字 / 反向风险必含一个量化指标 / 结尾用"决策矩阵"型金句（如"如果 X 就 Y，不 X 就 Z"）。
**推荐形式**：Thread（5-7 条）+ 1 张数据图（板块对比表 / 时间轴 / 热力图）。
**禁用**：❌"X 板块全解析"（太大没差异化）❌"X 是新风口"（跟风调）❌"我觉得 X 会涨"。

## 13. 🪞 反差叙事 / 第三方视角（24-72h）
**Hook 模板**
- "一位{第三方身份}，{动作}了{时间/数量}，{反差结论}"
- "{圈内人}的{属性 A}，{反常事实}"

**结构**：第三方视角（外人讲 / 跨文化观察 / 行业外报告）+ 反差对比（此地 vs 彼地 / 圈内 vs 圈外 / 谦逊 vs 张扬）+ 数据与引用关键句。
**为什么有效**：第三方视角破"自我宣传"嫌疑；具体数量词（"10 天 / 十几家"）提供质感；引号金句便于二次传播。
**适用**：跨文化对比 / 行业生态 / 产品实测见闻。

## 14. 🎭 人物花絮 / 反差感（24-72h）
**Hook 模板**
- "「{反差金句}」—— {大人物}{反常细节}"
- "{大人物}的日常，{反预期}"

**结构**：大人物 + 朴素或反预期细节 + 第一手采访/对话引用 + 自带笑点或反讽。
**为什么有效**：反财富/反权威人设 + 强反差细节，让圈外用户也愿意转。
**适用**：创始人报道 / KOL 人设 / 投资大师 / 富豪故事。

## 15. 🔢 一句话 + 量级对比（24h+）
**Hook 模板**
- "{事实}：{对象 A} > {对象 B——国家 / 行业 / 历史级别的参照物}"
- "{1 句话}。"（句号收尾，刻意短）

**结构**：一句话浓缩事实（0 废话）+ 强对比框架 + 数字震撼。
**为什么有效**：单句 + 句号 + 排除式表述 + 跨界对照（公司 vs 国家）。
**对比模板速查**

| 对象 A | 比 | 对象 B |
|---|---|---|
| 某龙头公司市值 | > | 除前两大经济体外任一国家 GDP |
| 某巨头市值 | > | 大盘指数后 200 家总和 |
| 1 个 AI 数据中心年耗电 | = | 一个中等城市/小国用电量 |
| 某巨头月度资本开支 | > | 一项历史级国家工程总成本 |

## 16. 🎙️ 借大佬之口反共识（4-48h）
**Hook 模板**
- "{权威}观点：所谓'{共识叙事}'，纯粹是一种**{贬义形容词}**的{描述名词}。"
- "{权威}：'{反共识金句}'。{反差事实数据}。"

**结构**：① 借权威之口（第三方背书）② 直接立场（不含糊）③ 反差事实（数据反证）④ 自嘲 / 接地气（拉近距离）。
**与 #3 的区别**：#3 是作者亲自下反共识立场；#16 是**借权威下立场**——降低争议风险 + 借来可信度。
**适用**：任何"强共识被权威公开反对"的场合（技术性失业、衰退预期、赛道叙事、监管争议）。
**权威清单**：按你的赛道自建并维护——AI（公认研究者 / 头部公司创始人）、宏观（知名经济学家 / 对冲基金创始人）、加密（核心开发者 / 交易所创始人）、股票（明星基金经理）。**引用必须是可查证的公开发言，禁止转述加工。**

## 快速使用指南

**按话题类型**：热点共识 → #1 或 #5 / 新数据发布 → #2 / 风险信号 → #3 / 市场大事件 → #7 + #8 / 需要深度 → #8 / 需要判断 → #9。
**按时效**：<4h → #7 / 4-24h → #1、#2、#3 / 24h+ → #6、#8、#10、#11 / 板块爆发 → #12。
**按风格**：强观点 → #1、#5、#16 / 数据驱动 → #2、#9、#10、#15 / 教育输出 → #4、#6、#8、#11 / 人物向 → #13、#14。

**一题多角度**：同一话题用 3 个不同模板能得到 3 个深度完全不同的角度。例如一个"资金流入型"话题：#1 直击"都看好"的对立面 / #2 用数据讲流动性故事 / #3 指出流动性可能反向的隐藏风险。
