# Community Weekly (c2 — 周报·简体)

供社群运营者使用。以一篇 600–800 字（最多 900 字）的白话周报，帮新手看懂市场怎么走、哪些事改变预期、下周留意什么。核心价值是可信、有用、可追溯，不是堆砌消息。

## 数据边界

- Followin MCP 是主要数据来源。市场、财报与事件时间都必须能回溯到本次返回。
- 重要宏观日期可用官方日程交叉确认；无法核实就不写。
- 单一媒体、匿名消息或未证实传闻只能标示为“市场传闻／尚待确认”，不可写成事实。
- 空值、过期、矛盾或不可靠的数据直接略过；禁止为了凑齐段落写“暂无数据”。
- 不提供买卖、目标价、仓位或操作建议。

## 调用序列（额度标称 ≈2–4＋关注池÷5）

| 步骤 | 调用 | 额度 |
|---|---|---|
| 1 | `metrics(query="SPY QQQ DIA VIX 行情", asset_type="tradfi")` 市场底色四标的日线收盘（若 `time_range=7d` 返回小时线，改 30 日区间日线重跑一次 +1） | 1–2 |
| 2 | `news(query="<事件关键词>", time_range="7d")` 本周主线事件，必要时换关键词补查 ≤3 次（搜索模式不传 asset_type，红线 1） | 0（实测） |
| 3 | 关注标的逐批（≤5 只）`metrics(query="<T1> <T2> … next earnings date", asset_type="tradfi")` 查下次财报日期 | ⌈N/5⌉ |
| 4 | `metrics(query="economic calendar upcoming releases")` 下周经济日历（非个股查询不传 asset_type；query 严禁带"本周"，红线 10） | 1 |
| 5 | （可选）`signal(query="consensus", asset_type="tradfi", time_range="7d")` 选择性信号 | 0–1 |

> 调用形态（N-8／红线 4）：`keywords=[...]` 等数组入参已被 tool schema 拒，任何客户端均不可用，一律走 query 空格拼串；批量上限 **5 个**，超出被**静默截断且无任何 warning**，调用后必须拿请求列表与 `meta.filters_applied.keywords` 做差集自查，缺的分批补。

## 执行流程

### 1. 市场底色

默认使用最近一个完整交易周；周中试跑时，明确写出比较区间与截至哪个收盘日。

用 `metrics` 获取 SPY、QQQ、DIA、VIX 的**日线**收盘数据。若 `time_range=7d` 返回小时线，改用 30 日区间日线，取周初与周末收盘计算周变动；不得把盘中小时数据当成周报收盘表现。只保留实际可计算的数字与截至日期。

### 2. 本周主线

用 `news` 搜索最近 7 天的重要美股事件，必要时再用公司、行业或关键词补查。选择 2–3 条同时具备“事件明确、与市场相关、能用白话说明”的主线。

财报以 `metrics` 的 Beat/Miss、营收、EPS、指引等结构化字段为准，新闻只补背景。不得使用市场级财报日历当素材，也不得把未经价格验证的新闻涨跌幅写入正文。

### 3. 下周已确认事项

用 `metrics` 查询未来 7 天经济日历，拆成两段日期窗口。只选高影响、日期与时间可核实的 2–5 项；优先利率决议、通胀、就业、GDP、PMI。

关注标的最多 5 只，逐只查询下一次财报日期；只有落在未来 7 天且可核实者才列入。没有就不写个股财报。宏观与财报时间一律标注“美东／北京时间”双时区，并加注“非完整清单”。

### 4. 选择性信号

`signal` 只作加分素材，不是必填。

- KOL：若 `time_range=7d` 未被完整支持，只能写“近日”，不可写“近 7 天”；没有可追溯聚合计数就略过。
- 交易员仓位：至少 2 位活跃交易员，且每一笔引用均有非空名义金额，才可写方向或合计；任一条件不符即略过。
- 内部人：只采用 P（买入）与 S（卖出）等可辨识交易；其他类型不延伸解读。

## 整合规则

1. 合并同一事件的重复报道，事实与 AI 推断分开写。
2. 每条主线只保留：最重要事实、为什么重要、下一个验证信号。
3. 推断使用“市场呈现”“可能反映”“后续观察”等中性措辞；不把相关性写成因果。
4. 单一来源必须标示“尚待确认”；若不适合对外说明就不收录。

## 对外贴文格式

```
📌 美股周报｜[起日]–[止日]

一句话先懂：[本周最重要的市场变化]

本周市场：[SPY]、[QQQ]、[DIA]、[VIX] 的周变动（截至[日期]收盘）。
[一句白话解释市场风格或波动变化。]

本周重点：
1️⃣ [事件]｜[可验证事实]｜为什么重要：[白话解释]
2️⃣ [事件]｜[可验证事实]｜接下来观察：[下一个可验证信号]
（最多 3 条；传闻必须标示尚待确认）

下周已确认事项（非完整清单）：
・[日期] 美东[时间]／北京时间[时间]｜[事件]｜为什么重要
・[日期] 美东[时间]／北京时间[时间]｜[事件]｜为什么重要

本周结论：[用 2–3 句中性整理市场正在重新定价什么。]

今日名词：[术语]
[不超过 2 句的白话解释。]

数据来源：Followin MCP 的 metrics、news（及实际使用时可验证的 signal）；重要日期以官方公告交叉核对。
⚠️ 以上整理自公开研报与市场数据，仅作信息分享，不构成投资建议。
```

## 发布前检查

- 简体中文、白话、600–800 字（最多 900）✓
- 市场数字有收盘日期且可追溯 ✓
- 财报数字来自结构化数据或已交叉核对 ✓
- 宏观／财报时间有美东与北京时间双时区 ✓
- 传闻已标示或已删除 ✓
- 不可靠的情绪、仓位、个股财报段落已省略 ✓
- 无投资建议、无煽动措辞、附来源与免责声明 ✓
