# Earnings Screener — 财报季超预期扫描

**每个财报季，从几百家刚发完财报的美股里，挑出「业绩确实大幅超出华尔街预期」并且
「电话会上管理层亲口说了产品不够卖」的那几家，把原话一并给你。**

## 它替你干的活

财报季（每年 1、4、7、10 月）每周上百家美股发财报。想从里面找出真正值得研究的，得做两件事：

先从一堆数字里挑出**营收和利润明显比市场预期高**的公司；再去翻这些公司的**财报电话会记录**——
每份四五万字——看管理层有没有说过「订单排到明年」「产能跟不上」「产品价格还能往上走」这类话。

一个人翻，一个季度也翻不了几家。

## 怎么做的

1. 从当天成交最活跃的股票、以及近期财报报道里，捞出刚发过财报的美股
2. 逐个核对营收和每股收益到底超出预期多少，不够格的直接淘汰
3. 对剩下最好的几家，把整份电话会记录从头读一遍，找七类「生意很旺」的表述
4. **只有「业绩」和「说法」两项都达标的，才进最终名单**

## 你拿到什么

一张短名单。每家附上管理层的**原话、是谁说的、是主动讲的还是被分析师追问出来的**——
以及同样重要的：**同一场会上他们说过的坏消息**（比如要大幅加码开支、某块业务在下滑）。

另有一节「即将发财报」，列出候选里下周要公布的公司。

## 怎么用

**1. 接入 Followin MCP**（需要 `metrics` 和 `news` 两个工具）：

```bash
claude mcp add followin https://mcp.followin.io/v2/mcp --scope user --transport http --header "x-api-key: YOUR_API_KEY_HERE"
```

**2. 装 Skill**：

```bash
cp earnings-season-screener.md ~/.claude/commands/
```

Cursor / Windsurf / Cline 把正文粘进各自的规则格式即可，纯 Markdown 完全可移植。

**3. 说一声就跑**：「财报季扫描」「本周谁业绩大增」「earnings screener」都能触发。中英文都行，输出跟随你的提问语言。

| 参数 | 默认 | 说明 |
|---|---|---|
| `days` | 7 | 往回看几天的财报 |
| `top` | 5 | 最多精读几份电话会记录 |
| `watchlist` | 无 | 空格分隔的股票代码，额外查这几只的下次财报日 |

> 💡 **建议开一个新会话跑。** 每份电话会记录约 50 KB，读 5 份就是 250 KB，会占掉大量上下文。
> 单次消耗约 10 次 Followin 额度。

## 为什么两项都要看

只看数字，会挑到财报好看但管理层心里没底的公司；只看管理层怎么说，会挑到话说得漂亮但业绩没兑现的。
**两边对得上，才算信号。**

所以它还会**主动找反面证据**：实测某只股票七类正面表述全中，而同一场会上财务总监也说了要大幅加码开支、
某块业务在下滑——只盯好话会完整错过这一半。

它也会**核对利润口径**：数据源里两套算法的每股收益并存且不标明，实测某只显示「超预期 100%」，
换成通用会计准则算是**净亏 110 亿美元**。这种情况会在输出里明确标出来。
